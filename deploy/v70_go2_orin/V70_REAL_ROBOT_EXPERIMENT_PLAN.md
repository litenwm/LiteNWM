# V70 实机导航与论文实验方案

## 1. 当前代码边界

本地 `deploy/v70_go2_orin` 包含 DINOv3、NoMaD、LTWM、Arm-D selector、
CEM 影子规划，以及 fail-closed 的 `safe_bridge`。静态检查没有找到完整导航循环、
最终目标到达检测器或 `motion_executor` 实现。因此：

- 可以确认影子规划的候选生成、评分、选择和安全门控；
- 不能仅凭当前本地仓库确认真机现有“接近终点后停车”的具体实现；
- 真正闭环测试前，应另行审查板端导航进程中的目标检测、速度锁存和恢复逻辑。

## 2. 推荐的终点停车状态机

不要把“selector abstain”“机器人速度低”或单帧图像相似当作到达目标。建议使用：

`NAVIGATE -> APPROACH -> GOAL_CANDIDATE -> STOPPED`

### NAVIGATE

- 使用当前观测历史和当前局部图像子目标规划；
- 对最终目标不可见的长程任务，不直接把远距离最终图片交给短视野 LTWM。

### APPROACH

- 当最终图像节点成为当前活动子目标，且视觉/时序距离进入近目标区间时降速；
- 继续使用独立几何安全层，不能因为接近目标而放宽障碍物约束。

### GOAL_CANDIDATE

要求若干个连续、时间同步且非陈旧的规划周期同时满足：

1. 当前观测和最终目标的视觉到达分数超过经真机数据校准的阈值；
2. 若目标姿态可由里程计或拓扑节点约束，位置和朝向也在容差内；
3. 视觉定位没有跳到外观相似但错误的节点；
4. 机器人已降至可安全停车的低速；
5. 该判定不是由障碍物、无安全候选或传感器超时触发。

建议使用进入/退出两个不同阈值形成滞回，并在真实接近序列上做 ROC 或
precision-recall 校准，而不是凭单张照片手设一个相似度阈值。

### STOPPED

- 以固定频率持续发布零速度，直到新目标或人工复位；
- 安全桥保持 stop/arm/heartbeat 门控；
- 传感器陈旧、目标置信不足或定位冲突时进入“安全保持”，但不要将其记录为导航成功；
- 目标确认与安全停车分别记录原因码。

官方 Visual Navigation Transformer 示例只用预测时序距离推进拓扑节点，并在最后节点
发布 `reached_goal`；其 PD controller 收到后发布零速度并退出。这适合作为最小参考，
但对 Go2 论文级实机验证不够稳健，尤其缺少多周期确认、滞回和持续零速度锁存。

## 3. 长程导航设计

V70 的 NoMaD 候选和 LTWM 未来预测属于局部、短时域规划器。长程导航应在其外部增加
拓扑层，而不是扩大局部动作角度、动作尺度或直接外推 LTWM 预测时域。

### 已知环境

1. 人工遥控记录一条参考路线；
2. 按行驶距离和视觉变化选择关键帧，形成图像节点；
3. 边记录可通行方向、经验行驶时间、风险、失败次数和可选里程计位姿；
4. 当前观测在局部窗口中定位到图节点；
5. A* 或 Dijkstra 选择下一图像子目标；
6. NoMaD 产生 K 个局部候选，LTWM + selector/CEM 选择当前边的动作；
7. 到达中间节点只切换子目标，到达最终节点才进入终点停车状态机。

### 未知环境

1. 使用 NoMaD goal-masked 模式或受限的局部探索候选；
2. 在线添加已到达节点和可通行边；
3. 对探索前沿按目标启发式、预期进展和风险排序；
4. 连续若干周期无进展、反复 abstain 或边执行失败时，标记该边并回退；
5. GPS、楼层图或粗略地图只能作为全局启发式，局部可执行性仍由视觉模型和几何安全层判断。

一个与本研究匹配的边代价可写为：

`edge_cost = time + lambda_risk * ArmD_risk + lambda_unc * ensemble_uncertainty
             + lambda_fail * edge_failures - lambda_progress * LTWM_goal_progress`

第一版“示教路线 + 图像拓扑图”通常不需要重新训练，只要相机视角、动作归一化和局部
子目标间距仍在训练支持范围内。若切换相机高度/视场、动作定义、全新地形，或希望可靠
执行 goal-masked 未知环境探索，应补采真机数据并微调或重新训练相关模块。

## 4. 最小可信实机实验矩阵

### A. 局部图像目标导航

- 8--12 条路线，覆盖 5--15 m；
- 每个方法、每条路线至少 5 次独立重复；
- 室内走廊、门口/岔路、桌椅杂物、窄通道、室外人行道；
- 加入光照变化、起始朝向变化和少量场景重排。

对照至少包括：

1. NoMaD 单候选或默认选择；
2. NoMaD + 固定 K17 selector；
3. NoMaD + LTWM + selector；
4. NoMaD + LTWM + selector + CEM；
5. 三域模型去掉一个域或去掉 ensemble 的消融。

### B. 候选选择诊断

- 椅子位于左前方、右侧可绕；
- 左右均可行的岔路；
- 正前方临时障碍；
- 窄门框和柱子；
- 无安全候选时的 abstain。

每次保存 K17 原始候选、三域分数、过滤原因、CEM 每轮样本和最终动作。

### C. 长程拓扑导航

- 第一阶段：50--150 m 室内多转弯路线；
- 第二阶段：200--500 m 室外或室内外混合路线；
- 包含视觉相似的多个门口、路线交叉、临时封路和一次回退；
- 固定示教拓扑图与在线构图分别测试。

不必为了“长程”立即追求公里级。先证明局部规划器能稳定执行图边、定位不会跳节点、
边失败可以回退，证据比一次偶然的超长成功更有价值。

### D. 三域泛化

- RECON 风格：普通室内/开放环境；
- SCAND 风格：行人丰富的社交环境；
- SACSoN 风格：办公室、走廊或人行道偏好；
- 同一路线比较三域 ensemble 与单域模型。

### E. 终点与失效模式

- 正确目标、外观相似错误门口、视角变化目标；
- 站立拍摄目标与站立导航；
- 模糊、曝光、局部遮挡；
- 障碍物导致停车与真正到达目标的区分；
- 传感器陈旧、里程计跳变、无安全候选；
- 记录提前停车、越过目标、在目标附近振荡和错误目标四类失败。

## 5. 指标

不要只报告成功率。至少报告：

- Success Rate 和带 95% 置信区间的成功次数；
- 最终目标距离、成功阈值及阈值来源；
- SPL 或相对参考路径长度；
- 碰撞/接触次数、人工接管次数、急停次数；
- 最小障碍物净空；
- 路径平滑度、规划频率、任务耗时；
- 终点检测 precision/recall、提前停车率、越过目标率；
- 拓扑节点定位误差和回退次数；
- abstain 触发率，以及 abstain 后恢复成功率；
- DINOv3、NoMaD、LTWM、selector、CEM 和完整周期的 p50/p95 板端延迟。

## 6. 论文实机照片与图

### 必拍素材

1. Go2 + Orin + 前视相机/雷达的整机图，并标注传感器；
2. 每个任务的当前观测与目标图成对展示；
3. 室内、行人/社交、室外三域场景各一张；
4. 典型障碍物场景上叠加 K17 候选，标出被拒绝候选和最终选择；
5. 同一场景中 CEM 第 0/1/2 轮候选收敛；
6. 长程路线的平面图/航拍图与图像拓扑节点；
7. 动态行人或临时障碍的连续 3--4 帧；
8. 无安全候选时保持零动作的安全案例；
9. 远距离、接近、确认、停止四阶段到达序列；
10. 一个真实失败案例及其分数/原因，避免只展示成功案例。

### 原始数据必须同步保存

- 每个规划周期的四帧观测和目标图；
- 相机、雷达、里程计原始时间戳；
- NoMaD 候选和归一化前后的动作；
- LTWM 预测特征、三域 scorer/Arm-D 输出和不确定性；
- selector/CEM 的候选排序、过滤原因、最终动作；
- 导航状态机、目标确认计数、停车原因码；
- 完整路线视频、外部固定机位视频和人工接管记录；
- Orin 的功耗模式、温度、时钟和延迟日志。

使用固定起终点标记、固定拍摄机位和预先登记的重复次数。所有失败均保留；人物出镜应
取得同意或在投稿前匿名化。

## 7. 最适合本研究的论文图结构

主实机图建议包含：

1. `Observation + Goal`；
2. `NoMaD K17 candidates`；
3. `DINOv3/LTWM imagined latent futures`；
4. `Tri-domain risk and uncertainty`；
5. `Selector/CEM refinement and chosen path`；
6. `Executed route and reliable goal stop`。

另一张长程图展示拓扑图、全局子目标序列、三域典型场景、临时封路后的回退路线。

## 8. 相关工作依据

- [NoMaD](https://arxiv.org/abs/2310.07896)：真实室内/室外目标导航与探索，
  使用拓扑图处理长时域任务。
- [ViNT](https://arxiv.org/abs/2306.14846)：局部视觉策略配合拓扑图和长程启发式，
  展示公里级导航与动态行人场景。
- [ViKiNG](https://arxiv.org/abs/2202.11271)：以视觉可通行性作为局部控制，
  地图/GPS 仅作全局启发式，并支持试探和回退。
- [RECON](https://arxiv.org/abs/2104.05859)：潜在目标模型与非参数拓扑记忆，
  目标图可在约 80 m 外。
- [Navigation World Models](https://arxiv.org/abs/2412.03572)：用世界模型模拟并排序
  NoMaD 候选，也使用 CEM 优化动作序列，是本地 LTWM + selector/CEM 的直接方法学对照。
- [Can Vision Foundation Models Navigate?](https://arxiv.org/abs/2603.25937)：
  真实机器人评测指出碰撞、重复场景错误目标识别和分布偏移问题，并主张同时报告路径、
  视觉和鲁棒性指标。
- [NavWAM](https://arxiv.org/abs/2606.13494)：24 次室内闭环实机图像目标导航，
  同时报告未来预测、目标进展和动作，并讨论 CEM 成本、漂移和碰撞失败。
